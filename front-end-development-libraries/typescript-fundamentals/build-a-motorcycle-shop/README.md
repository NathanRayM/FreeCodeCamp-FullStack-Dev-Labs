# Build a Motorcycle Shop

**Description:**
In this lab, I built a motorcycle shop application using TypeScript that retrieves motorcycle data from an external API and dynamically renders a collection of motorcycle cards to the page. The application uses TypeScript interfaces to define the structure of the motorcycle data, asynchronous functions to fetch API data, and a class to manage the application’s state and rendering logic.

The goal of this exercise was to practice working with TypeScript interfaces, classes, access modifiers, asynchronous programming with async/await, DOM manipulation, and rendering dynamic content from an external data source. The project also demonstrates how to organize application logic into reusable functions and class methods while maintaining strong type safety.

**Technologies Used:**

- HTML5
- CSS3
- TypeScript
- Fetch API
- Async / Await
- DOM Manipulation
- Object-Oriented Programming (Classes)

**Setup / How to Run:**

1. Clone or download the repository.
2. Open the project folder.
3. Install dependencies:

```
npm install
```

4. Compile the TypeScript:

```
npx tsc
```

    (Optional: use npx tsc --watch to automatically recompile when changes are saved.)

5. Open the project using a local development server (such as the VS Code Live Server extension).
6. View the application in your browser.

**Learning Outcomes:**

- Defining custom data models using TypeScript interfaces
- Creating classes with private properties and public methods
- Managing application state within a class
- Fetching data asynchronously using the Fetch API and async/await
- Rendering dynamic HTML content from API data
- Transforming arrays using map() and combining HTML with join()
- Updating the DOM using innerHTML
- Compiling TypeScript into JavaScript using the TypeScript compiler (tsc)
- Organizing application logic into reusable, maintainable components
